Recency Ring System

Green/yellow/red rings on every map pin are the product's primary visual identity. Color = trust signal. Never use these colors for other UI purposes to preserve signal clarity.

Brand-defining

Dark Map Aesthetic

Dark basemap (slate-900) makes recency rings visually dominant. UI chrome matches — dark surfaces, high-contrast elements. No white backgrounds anywhere in the core map experience.

Visual strategy

Sky-Blue Primary

The single accent color for all interactive elements (buttons, FAB, links, active states). Sky-blue reads as "open sky / open road" — thematically appropriate and distinct from all recency colors.

Full-screen map

The map fills the entire screen. No persistent chrome at top or bottom. All UI elements float over the map — search bar, rig badge, layer toggle, FABs.

Rig filter badge

Always visible below search bar. Shows current rig and confirms filter is active. Tap to modify rig profile. Never hidden.

Greyed pins

Layer toggles

Left-side floating panel for show/hide by category. Compact, out of thumb's primary reach, but accessible. Persisted to localStorage.

Trigger timing

Prompt appears when user opens the app after being near a spot for 2+ hours, or when tapping a nearby "leaving?" notification (Phase 2). Never mid-stay, never repeated.

3-tap maximum

Tap prompt → select one option → tap Submit. Optional note field appears only if "Something changed" is selected. Never required.

Community framing

"Help the next traveler" is the core copy. Not "rate this spot," not "submit a report." Framing drives contribution as a community act.

One tooltip, one time

The recency ring is the only truly novel UX pattern. One non-intrusive tooltip on first map view explains it. No onboarding tutorial, no help center, no coach marks.

Positioned for context

Tooltip appears near the map, not overlaid on any pin. Designed to be seen, then ignored as the user starts exploring naturally.

Dismiss behavior

Any tap anywhere on the screen dismisses it. Tapping a pin dismisses it and opens the pin sheet simultaneously. Zero blocking of the core experience.

Why stepper, not slider

RVers know their exact dimensions (40 ft, 13'2"). A slider feels imprecise — "about 40?" is wrong when you're checking a 40ft clearance. Steppers give exact numbers with one-tap increments.

Foot + inch resolution

Length in 1-foot increments (20–55ft). Height in 1-inch increments (8'0"–14'0"). Most RV specs are given in feet and inches — we match that mental model exactly.

Defaults by rig class

Default values pre-populated from Step 1 selection (Class A → 35ft / 12'6" as starting point). User taps to fine-tune. Reduces friction, shows the app already knows their world.

The reveal moment

After tapping "See Your Filtered Map", the map animates — pins that exceed their dimensions grey out in real time. 2-second reveal makes the filter viscerally visible on first use.

Chips, not a filter sheet

iOverlander uses a modal sheet to pick categories. Opening a sheet adds 2–3 taps. Chips are always visible, always one tap. The mental model: "I want water" → tap Water. Done.

Multi-select AND logic

Selecting Water + Dump shows only spots that have BOTH. This is the most common real-world need: "I need to fill water AND dump the tanks before my next stop." One gesture, two requirements.

Active chip has ✕ to clear

Active chips show a ✕ so clearing a filter is a single tap on the chip itself — no separate "clear all" button needed. Tap to add, tap again to remove.

Live result count

When filters are active, a floating count shows "X matching spots nearby." This grounds the filter state — user knows immediately if they're being too restrictive before panning the map.

Propane as a chip

🔵 Propane fills a real gap — exchange tanks at travel centers are genuinely hard to find with confidence. One chip. RVers with propane fridges and furnaces will tap it immediately.

Scroll reveals more

7 chips fit without scrolling on most screens. Users who want Shower or Electric scroll right — the scroll shadow hints at more. Propane is chip 5 (core) — Electric and Shower are 6–7 (secondary).
